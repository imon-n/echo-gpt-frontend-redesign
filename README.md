# EchoGPT Frontend Redesign

A modern and responsive frontend redesign of an AI workspace application, built as part of a Frontend Software Engineering Internship assignment.

The goal of this project was to create a clean, practical, and responsive AI interface with a focus on usability, component reusability, and responsive design.

## GitHub Repository

[View the source code](https://github.com/imon-n/echo-gpt-frontend-redesign)

## Features

* Responsive landing page
* Login and registration pages
* Google login interface
* AI chat workspace
* Chat history interface
* Browser extension interface
* Responsive authentication layout
* Sidebar navigation
* Reusable React components
* Client-side routing
* Smooth UI animations
* Mobile, tablet, and desktop support

## Tech Stack

* React
* TypeScript
* Vite
* React Router DOM
* Tailwind CSS
* Framer Motion
* Lucide React


## Getting Started

Clone the repository:

```bash
git clone https://github.com/imon-n/echo-gpt-frontend-redesign.git
```

Go to the project directory:

```bash
cd echo-gpt-frontend-redesign
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will then be available at the local development URL provided by Vite.

## Design Approach

The interface uses a simple visual system built around white, zinc, and violet tones.

The design focuses on:

* Clear visual hierarchy
* Consistent spacing
* Responsive layouts
* Simple navigation
* Reusable components
* Subtle animations
* Accessible interactive elements

The authentication layout uses a two-column design on larger screens and switches to a single-column layout on smaller screens.

## Authentication

The project includes the frontend interface for:

* Email and password authentication
* User registration
* Google login

The Google login button is currently implemented as part of the frontend interface. A production authentication provider can be connected separately.

## Responsive Design

The application has been designed to work across different screen sizes, including:

* Mobile devices
* Tablets
* Laptops
* Desktop screens

Tailwind CSS responsive utilities are used throughout the project to adapt layouts and spacing.

## Animation

Framer Motion is used for lightweight animations and transitions across selected sections of the application.

The animations are intentionally kept subtle so they do not interfere with the overall usability of the interface.

## Purpose

This project was developed as a frontend engineering assignment to demonstrate practical experience with React, TypeScript, responsive UI development, routing, component architecture, and modern frontend tooling.
